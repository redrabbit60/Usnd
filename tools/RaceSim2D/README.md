# RaceSim2D — 2D競馬シミュレーター（実況音声タイミング確認用）

実況音声を別途再生しながら本画面を見て、「実況で言っているタイミングと馬の位置が
合っているか」を目視チェックするためのツールです。

## 使い方

1. `race_sim.html` をダブルクリックしてブラウザで開く（サーバー・ビルド不要）
2. そのまま「▶ 再生」を押すと同梱サンプルデータ（`sample_race.json` と同内容）で
   10頭のレースが再生されます
3. 実際のレースデータを確認する場合は、画面上部のファイル選択、または
   JSONファイルを画面へドラッグ＆ドロップして読み込みます

単一HTMLファイルで完結しており、別PCへ `race_sim.html` を1つコピーするだけで動作します
（外部ライブラリ・Unity依存なし）。

## 再生コントロール

- 再生 / 一時停止（スペースキーでも可）
- 先頭へ戻る
- 経過タイム表示（分:秒.1/100秒）
- 再生速度 0.5x / 1x / 2x
- シークバーで任意の時刻へジャンプ

## JSONデータ形式

```json
{
  "distance": 2000,
  "horses": [
    {
      "id": 1,
      "name": "サンプルホース1",
      "laps": [
        { "point": 200, "time": 12.5 },
        { "point": 400, "time": 24.8 }
      ]
    }
  ]
}
```

- `distance`: レース距離(m)。1000〜3600mに対応
- `laps`: 各通過点(m)と、スタートからの累積タイム(秒)。200m刻みを想定していますが、
  刻み幅は任意（通過点間は線形補間で位置を算出）
- 最終ラップがゴール距離に満たない場合は直前区間の速度で外挿してゴール時刻を補完します
- 表示レーンは常に10本（10頭想定）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `race_sim.html` | シミュレーター本体（サンプルデータ同梱・単一ファイル） |
| `sample_race.json` | 外部読み込みテスト用のサンプルデータ（2000m・10頭） |
